# Issue #28C — JSON 匯出／匯入規格

## 目標

提供可審查、可攜且不覆蓋既有桌面的第一版資料交換格式。第一版刻意只接受 JSON；ZIP、可執行檔與素材位元都不會被解壓、執行或隱式帶入。

## 匯出

- 公開匯出只包含已發布、可公開投影的內容。
- 私人草稿備份僅桌面擁有者可下載，並在封裝中標示 `owner-backup`。
- 文件內的站台 ID 會改成保留值 `export:site`，避免把來源內部 ID 當成新桌面 ID。
- 原始編輯網址與疑似簽名網址、憑證、權杖會被移除或阻擋。
- 素材清單記錄引用位置、來源、MIME 推測、權利說明與是否為私有素材，但不內嵌素材位元。

## 匯入

- 瀏覽器與 API 都限制為 2 MB，且只接受嚴格的 Retro JSON v1 schema。
- 先預覽內容數量與缺少的私有素材，再以該份內容的 SHA-256 摘要確認匯入，避免預覽後被替換。
- 每次匯入都建立新桌面與新站台 ID，絕不覆蓋來源或目前桌面。
- 若有未附檔的私有素材，必須明確勾選確認；匯入後由擁有者重新上傳。
- 路徑遍歷、未知欄位、超量清單、ZIP 與非 JSON 輸入都會拒絕。

## 後續相容性

未來若加入含素材的封裝，必須使用新的格式版本並新增：壓縮炸彈上限、檔名正規化、MIME／magic-byte 驗證、逐檔雜湊、授權清單與原子化匯入。JSON v1 的安全語意不會被悄悄改變。
