# Retro OC 平台：初始整體方向

日期：2026-10-16。這是本輪研究的起點；逐單調查後的收斂版本見 [整合設計](README.md)。

## 產品定位

讓創作者用一台可探索的復古桌面展示 OC、作品與世界觀。桌面是容器，角色是共用內容，不把每個視窗變成各自孤立的資料庫。

主要使用者是單一創作者；訪客不必登入即可探索已發布內容。多人共同編輯、真實社群、付費服務、外掛市集均不屬第一版。

## 首次完整體驗

創作者建立兩名 OC → 各自新增作品 → 設定彼此追蹤、誰喜歡作品、誰留言 → 訪客從名單點進另一名角色 → 分享該角色或貼文。

沿用 Win98 視窗、Cubic 11 字型、既有桌面編輯／手機單視窗規則。視覺豐富來自角色內容和關係，不以大量裝飾或無功能的選單增加複雜度。

## 初步拆分

1. 基礎：資料版本、共用角色、公開資料邊界、素材授權。
2. 主線：OC Instagram，多角色、貼文、圓形精選、虛構互動、可分享連結。
3. 擴充：Music、Moodboard、Explorer 各自可發布，不互相綁死。
4. 後期：留言簿、真實協作、外部擴充規格。

## 調查問題

- 現有 registry 是否已足夠？哪些能力真的缺少？
- 舊 IG 資料怎麼無損轉成多角色？
- 「隱藏視窗」「未列出」「草稿」「私密素材」是否具有不同語意？
- 能否沿用原生 React/CSS，只在確有收益時引入開源模組？
- 開源程式碼授權能否涵蓋圖示、字型、參考作品？
- 分享、發布、匯出是否使用同一份公開快照？

以上為設計假設；以各單的原始碼調查、外部來源與最終決策修正，不宣稱已實作。
