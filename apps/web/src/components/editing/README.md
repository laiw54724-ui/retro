# Shared editing controls

Import from `components/editing`. The barrel includes the shared CSS. Host editors retain canonical writes, history recipes, upload ownership and permissions. These controls never save, upload or publish on their own.

All containers accept optional `tv`, `mobile`, `className`, and `style`. Supply the existing theme view; defaults match the classic theme. Pass `mobile` on the appropriate container for 44px touch controls. Existing renderer and persisted `window.type` names are unchanged.

- `InlineTextField` / `InlineTextArea`: native input/textarea props and forwarded refs, plus `onValueChange(value, historyKey?)`, `historyKey`, `onEnter(event)`. `onChange` remains supported. Enter callbacks ignore composition and keyCode 229. Textareas preserve newlines and resize automatically.
- `SortableList<T>`: `items`, `onMove(id, toIndex)`, `renderItem(item, handle, state)`, `label`, optional `endSlot`, `rowClassName`, `getRowProps(item)`, `onDraggingChange`. Each stable keyed row wraps `renderItem`; use `getRowProps` to retain listbox option semantics and primary keyboard behavior. Prevent default in the row handler to override the shared Alt+arrow behavior. Only handles are draggable. The list announces a completed move.
- `PopoverPanel`: `open`, `onClose`, `triggerRef`, `scopeRef?`, `label`, `floating?`, `keepMounted?`, `showDone?`, `doneLabel?`, `shouldCloseOnOutside(target)?`. The caller owns the one-open-key state and the trigger's `aria-expanded`. Hidden mounted panels retain child drafts. Clicks within modal dialogs or elements marked `data-editing-owned-portal` do not close the panel; a predicate can recognize additional owned portals. Nested popovers/menus handle their own Escape first. Deliberate focus on another control is preserved.
- `DestinationChip`: forwarded button ref; `text`, `icon?`, `missing?`, `expanded?`, native button props. The full `title` defaults to `text`; the visible destination truncates.
- `UrlPasteBar<G extends PasteGuess>`: controlled `value`, `onChange`, `classify(raw)`, `onAdd(guess)`, `label`, `placeholder`, optional `inputId`, `inputLabel`, `addLabel`, `extra`, `disabled`, `maxLength`. The generic guess can retain the canonical source/URL as additional fields. Invalid guesses are still passed to `onAdd` so the host can show its error banner; the bar never commits or clears itself. `normalizePastedUrl` offers conservative domain/email normalization; the host still validates allowed schemes.
- `FileDropZone`: native div props/ref; `accept: image|audio`, `maxBytes`, `multiple?`, `disabled?`, `onFiles(files,{x,y})`, `onError(message)`, `overlayText?`. Coordinates are browser client coordinates for the host's insertion calculation. Valid files retain input order, invalid files produce an error; upload work remains with the host queue. Nested zones consume their own drop. A supplied native `onDrop` may prevent default to take complete ownership.
- `InlineErrorBanner`: `message`, `onClose`. Persistent alert above the status bar; the host must be positioned.
- `EditorStatusBar`: `message`, `count?`, `problem?`, `temporaryMessage?`, `temporaryMs?` (3000). Problem text wins over a temporary message. The message cell is a polite atomic live region.
- `ContextMenu`: `items: {id,label,onSelect,shortcut?,disabled?,danger?,primary?,separatorBefore?}[]`, `label`, `position:{x,y}`, `containerRef`, `onClose`, `returnFocusRef?`. Position is relative to the positioned host. Host opens it for right-click/Shift+F10/ContextMenu. It handles arrow/Home/End/Tab/Escape and clamps to the host.
- `FloatingSelectionBar`: `rect:{x,y,width,height}`, `containerRef`, `hidden?`, `label`, children. Rect is in host-local screen pixels. Place it in the same positioned host; it flips below a top-edge selection and clamps horizontally. Host hides it during dragging/text editing.

`locale-deltas/*.json` are the eight shared `editor.editing` strings in four languages, delivered for the integration owner. The controls prefer the real catalog and use these translated fallbacks if a downstream branch has not merged the catalog yet. No test injects translations.

Verification: component contracts in `editing.test.tsx`; browser fixture and dual-engine configuration in `tests/editing-primitives`, interactions in `tests/e2e/editing-primitives.spec.ts`. The fixture is test-only and is never imported by the application.
