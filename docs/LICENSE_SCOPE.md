# License scope and unresolved release decision

Retro's repository owner has not yet selected and granted a root source-code license. Until a root `LICENSE` is added by an authorized rights holder, the public repository is source-available for inspection but no open-source redistribution license should be inferred.

When the owner selects a license, it must clearly apply only to original Retro source and documentation they have authority to license. It must not relicense:

- Windows/application icons in `/windows-icons/` or `/win98-icons/`
- Cubic 11 beyond its separate SIL Open Font License 1.1 terms
- user uploads, OC artwork, music, lyrics, avatars, or exported sites
- third-party names, marks, screenshots, and reference material

See [the machine-audited asset boundary](THIRD_PARTY_ASSETS.md). The redistribution gate must remain blocked until every bundled collection is confirmed or removed/replaced.
